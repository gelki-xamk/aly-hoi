# aly-hoi
Aivojumppatehtäviä

1. Kloonaa tämä repositorio koneellesi käyttäen komentorivityökaluja tai Visual Studio Codea
2. Asenna Vite-kehitystyökalut React-ohjelmointia varten komennolla
npm create vite@latest . -- --template react-ts
Noudata asennusohjeita oletusasetuksilla
Kun Vite varoittaa asennuksen yhteydessä olemassa olevista tiedostoista, valitse "Remove existing files and continue"
